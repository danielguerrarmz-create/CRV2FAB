Sketch with three strokes: the start profile (blue, across the width at the start), the end profile (purple, at the end) and the bending path (orange). Any you skip keep the current member's. Use Rotate view between strokes: each stroke stays fixed to the model, so draw profiles looking along the member. The member's centreline is drawn with orange control points. Claude gets the shape, the limits and why it fails, tests candidates with the same check, and returns a new shape with its reasoning. A sketch is checked first; if it fails, Claude gets your sketch image and keeps its shape as far as it can.
