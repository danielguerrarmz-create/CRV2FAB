# CRV2FAB logo

The card's title bar and the CRV2FAB panel tab take their icon from this folder. To use new art,
replace the files and keep the names:

- `crv2fab.ico`: one icon file holding 16, 24, 32 and 48 px images.
- `crv2fab.png`: the same logo, 256 px square, for documents.

The current files are Daniel's choice, option B: a tan ribbon with a half twist (Sai, 2026-11-15).
If the icon is missing or cannot be read, Rhino's default icon is used.
